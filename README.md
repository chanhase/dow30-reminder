# ダウ30 暗記カード

企業名・ティッカー・主な事業と、業種ごとの採用企業を覚えるブラウザ用ツールです。

## 使い方

`index.html` をブラウザで開きます。サーバーやインストールは不要です。

- 企業ごと：企業名またはティッカーを表にして答えを確認。
- 業種から企業名：業種と採用企業数をヒントに、その業種の企業名を思い出す。
- 「もう一度」と判定したカードだけ復習できます。
- 学習判定はページを開いている間だけ保持します。
- キーボード：Spaceで答え表示、1で「もう一度」、2で「覚えた」。

## データ

構成銘柄とGICSセクター分類は2026年10月1日時点の固定スナップショットです。
業種カードは9枚、合計30社です。企業数はデータから計算します。

出典：
- https://whichindex.com/indexes/dow-jones/
- https://www.ssga.com/us/en/individual/etfs/state-street-spdr-dow-jones-industrial-average-etf-trust-dia
